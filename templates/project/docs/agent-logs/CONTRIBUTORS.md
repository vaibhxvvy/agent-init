# Contributor Roster

> One row per identity writing to repo. Handle used for logs (`docs/agent-logs/<handle>/YYYY-MM-DD-HHmm.md`), branches (`<handle>/<task>`), log `agent:` field.
> Setup: `git config init.contributor <your-handle>` (`[a-z0-9-]` unique). Scaffold `<handle>/README.md` same session.

| Handle | Person / agent | Branch prefix | First seen |
| ------ | -------------- | ------------- | ---------- |
| `admin` | Repo owner (squash-merges) | `admin/` | YYYY-MM-DD |

> Only admin squash-merges PRs into `main`.
